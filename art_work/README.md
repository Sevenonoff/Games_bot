# art_work — картинки пути «Дорога за облака»

Рабочая папка генерации картинок для пути (картинка над меню бота, «Мой путь», «Герои»). Здесь всё, чтобы
продолжить работу в новой сессии. В git лежат только скрипты и тексты; картинки (png/jpg/webp), логи,
`rejected/`, `page_*/`, `gen/out/` — в `.gitignore` и есть только на этой машине.

## Что уже сделано (TG 2.7.0, коммит 436305c, выложено 2026-11-20)

- **Сюжет «Дорога за облака»**: путник с картой идёт из родной долины к Облачной горе. Каждая локация продолжает
  предыдущую (в левом нижнем углу — кусочек прошлой), сюжет бесконечный. Глава = 8 локаций ≈ неделя каждая.
  План глав 2–10 и «второго круга» — на странице сюжета (ссылка ниже) и кратко в конце этого файла.
- **Глава 1 «Родная долина»**, локации 1–8: 🏡 Луг у дома, 🎃 Ферма тётушки Бурёнки, 🍎 Пасека и яблоневый сад,
  🏘 Деревня на холме, 🎡 Летняя ярмарка, 💧 Водяная мельница, 🪁 Холм ветров, 🗼 Опушка и сторожевая башня.
  У каждой: фон, картинка «после» (видна у пройденной локации), слои высоких предметов, тропа.
- **Герои** (8 шт., рисовала нейросеть): лисёнок, котик, мишка — бесплатно; зайка 40, пингвин 60, совёнок 90,
  динозаврик 120, робот 150 монет. **Монеты**: 1 за шаг + 10 за сундук в конце локации.
- Все игроки начали путь заново с локации 1 (`motivation.JOURNEY_EPOCH`).
- После главы 1 (с локации 9) бот пока рисует старые зоны кодом (начиная с «Леса») — **главу 2 нужно сделать
  до того, как игроки дойдут до локации 9, ≈ через 2 месяца** (≈ середина января 2027).

## Как устроено в боте (кратко)

- Ассеты: `games_core/art/journey/loc<N>/` — `bg.jpg`, `after.jpg`, `occ_*.webp` (слои), `loc.json`
  (тексты, тропа в долях 0..1, слои с x, y и «основанием» base); общие `coin.png`, `chest.png`,
  `heroes/<герой>.png` (112 px) и `<герой>_big.png` (200 px).
- `games_core/locations.py` читает `loc.json`; `games_core/journey_scene.py` собирает кадр 1280×720 JPEG:
  size+1 точка по тропе, герой на точке step, монеты дальше, сундук на последней; слои и предметы
  сортируются по y основания (мельница рисуется поверх монет за ней); герой поверх всего ещё раз на 45 %
  (виден силуэтом за домом).
- `games_core/heroes.py` — экран «Герои», покупка/выбор (payload `hr`, `hrb`).

## Конвейер одной локации

1. **Сцена** (`chapter1/run.py scenes [ids]`): промпт из `spec.py` (`scene_prompt`), **без картинок-образцов**,
   3 варианта, автоматический выбор по `path_score` (длинная одна тропа от левого низа к правому верху) →
   `loc<N>/orig.png`. Выбор обязательно проверить глазами; ручной выбор — `run.py pick N V`.
2. **Правки** (`run.py edits`): «чистая» версия без высоких предметов (`CLEAN_PROMPT`) → `clean.png`;
   картинка «после» (`loc["after"]`) → `after.png`. Обе — правка `orig.png` той же моделью.
3. **Сборка** (`chapter1/build.py [ids]`): тропа ищется по `clean.png` (`gen/trace.py`: маска светлого
   песка в HSV → скелет → самый длинный путь); слои = разница `orig` и `clean` (размытие, порог 38, отсев
   кусков, которые на оригинале на 55 % песок, меньше 900 px или больше 20 % кадра) → WebP.
   Если тропа нашлась неверно — опорные точки вручную в `chapter1/manual_paths.json` (проценты, от начала
   к концу); так сделаны локации 2 и 7.
4. Проверить кадры (страница-обзор, как `page_chapter1/`), прогнать тесты, коммит/выкладка — только по
   просьбе.

Спрайты (монета, сундук, герои) генерировались листом на однотонном пурпурном фоне (#FF00FF) с промптами
`gen/prompts/coin.txt`, `heroes.txt` и вырезались `gen/sprites.py <лист> <префикс>`.

    `doubao-seedream-5-0-260128` отвечала «model not valid»).
  - GPT image: `/v1/images/generations`, ответ `b64_json`.
  - Траты: `GET /v1/dashboard/billing/usage`, поле `total_usage` в центах.
- Сервер Max, логи действий — см. память проекта (`~/claude-ops.log` на проде).

## Уроки генерации (дорого достались)

- **Не давать целую карту как образец** — Gemini копирует её планировку; фрагменты-образцы — копирует масштаб
  (камера «наезжает»). Работает: только текст + явный абзац SCALE («главное здание ≈ 1/8 ширины») + маршрут
  тропы своими словами для каждой локации.
- Маршруты, которые получаются: «вертикальный серпантин» (3, 6), «серпантин по склону из 4 отрезков» (4, 7),
  «широкая S на боку» (5, 8). «Разворот вокруг амбара» дал петли.
- Тропа должна быть **светлой песочной и на солнце** — иначе `trace.py` её не находит.
- «Чистая» правка иногда меняет саму дорогу → тропа по ней неверна. Каждую локацию проверять глазами.
- Явно запрещать текст, цифры, UI, монеты и метки на тропе — иначе модель их рисует.
- Каждая локация = 3 варианта + 2 правки = 5 вызовов. Gemini 3 Pro Image ≈ $0.11 за вызов; глава 1 вместе с
  переделками ≈ $5.6.

## Глава 2 «Зачарованный лес» — начато

`chapter2/spec.py` — стиль (как глава 1 + свет сквозь кроны), локация 9 «🍄 Грибная поляна» с текстами для
бота. `python3 chapter2/spec.py` пишет в `chapter2/loc9/`:

| файл | что |
|---|---|
| `prompt.txt` | полный промпт сцены (≈ 600 слов), как для глав 1 |
| `prompt_short.txt` | короткий (≈ 160 слов) — для моделей с ограничением длины (Flux, SD-подобные) |
| `clean_prompt.txt` | правка «убрать высокие предметы» |
| `after_prompt.txt` | правка «после» (сумерки, грибы светятся) |

Остальные локации главы (из плана сюжета): дом на дереве, лесное озеро, совиная библиотека в дупле, вечерняя
поляна светлячков, мастерская бобров, хижина травницы, Древний дуб (финал главы).

### Проба дешёвых моделей (цель — снизить стоимость)

Для конвейера модели нужны **две** способности: (1) нарисовать сцену с одной цельной тропой по маршруту и
(2) **править** картинку, сохраняя композицию до пикселя (clean и after). Дешёвая модель может годиться только
для (1) — тогда правки делать Gemini (2 вызова вместо 5 на локацию) или другой моделью правки.

Что оценивать у пробы:
1. Одна тропа от левого нижнего угла к правому верхнему, без развилок и петель, ширина ровная, ничего на ней
   не стоит → проверка: `path_score` из `chapter1/run.py` (≥ 2.5 — хорошо) и `gen/trace.py <картинка>`.
2. Масштаб «целого уровня» (не крупный план), много объектов из списка.
3. Стиль совпадает с главой 1 (сравнить с `chapter1/loc8/orig.png` рядом).
4. Нет текста и цифр.
5. Правка clean: убраны предметы, тропа не изменилась, остальное на месте.

Кандидаты (цены — ориентир по официальным ценам провайдеров, у CometAPI свои, проверять в кабинете):
Gemini 2.5 Flash Image (≈ $0.04), Seedream 4/5 (≈ $0.03), Imagen 4 Fast/Standard (≈ $0.02/0.04),
GPT Image mini (≈ $0.01–0.02 за medium), Flux (Kontext — с правкой), Qwen-Image / Qwen-Image-Edit.

## Чтобы добавить главу 2 в бот

1. Довести `chapter2/` до уровня `chapter1/`: `run.py`/`build.py` сейчас импортируют `spec` из своей папки —
   проще скопировать их в `chapter2/` (или вынести общее в `gen/`) и дописать в `build.py` `EMOJI` для 9–16
   (эмодзи уже лежит в `spec.py`, можно брать оттуда).
2. Собрать в `games_core/art/journey/loc9..16`; `locations.all_locations()` подхватит сами.
3. Поправить `tests/test_journey_scene.py::test_chapter_one_is_complete` (сейчас ждёт ровно 8 локаций главы 1)
   и `test_drawn_zones_after_the_chapter`.
4. Размер репозитория/образа: глава 1 ≈ 4.4 MB ассетов; контейнер Max ≈ 47 из 160 MB памяти.
