# Картинки пути

Фоны зон рисуются кодом в `games_core/journey_art.py`.

Чтобы поставить свой фон, положите сюда файл `zone_<номер>.png`, где номер считается с 0: `zone_0.png` — Луг, `zone_1.png` — Лес и так далее.
- Размер — 800×450 или любой с тем же соотношением сторон 16:9.
- Тропинка из плит, фигурка и облака рисуются поверх фона.
- Их координаты такие же, как у нарисованных кодом фонов, см. `path_points()`.
- Тропинка идёт змейкой в три ряда снизу вверх. Облака закрывают правый верхний угол.

`DejaVuSans-Bold.ttf` — шрифт DejaVu, свободная лицензия (Bitstream Vera / public domain), https://dejavu-fonts.github.io/. Нужен для кириллицы на открытках: в Docker-образе python:slim своих шрифтов нет.
